# 📸 My Gallery Project

A responsive and elegant image gallery built with **HTML** and **CSS**, featuring a modern grid layout and interactive hover effects for a smooth and engaging user experience. The layout seamlessly adapts to all screen sizes, offering optimal viewing on both desktop and mobile devices.

## 🚀 Features

- ✅ **Responsive Design** – Adjusts gracefully to various screen sizes using media queries and flexible grid layout.
- 🎯 **Clean Grid Layout** – Organized and visually appealing structure for showcasing images.
- ✨ **Hover Effects** – Smooth transitions and scaling effects on image hover to enhance interactivity.
- 📱 **Mobile Optimized** – Fast-loading, touch-friendly layout suitable for phones and tablets.
- ⚡ **Lightweight** – Built with pure HTML and CSS for quick rendering and zero dependencies.
